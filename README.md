# Paradise Nursery Shopping Application

An online plant shopping web application built with React, Redux Toolkit, and Vite. Paradise Nursery offers a wide variety of houseplants categorized for indoor styling, air purification, and aromatic qualities.

## Features
- **Landing Page:** Welcoming interface with background visuals and introduction to Paradise Nursery.
- **Product Listing:** Over 18 unique plants grouped across multiple categories (Air Purifying, Aromatic, Low Maintenance) with real-time cart status.
- **State Management:** Redux Toolkit-powered cart tracking item additions, removals, and quantity adjustments.
- **Shopping Cart Page:** Full breakdown of unit prices, item subtotals, overall cart total, and smooth navigation between views.

## Tech Stack
- React
- Redux Toolkit
- Vite
- CSS3
